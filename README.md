# DjurAccess – Julkampanj & Givarflöde

Fristående, privat utvecklingsrepository för DjurAccess julkampanj och givarflöde (React + Vite), förberett för att senare kunna införlivas i `djuraccess.se`.

## Regler för det här repot
- **Inga känsliga dokument** (inga föreningshandlingar, intervjuer, personuppgifter, interna driftloggar eller API-nycklar).
- **All testdata ska alltid prefixas med `TEST`** (t.ex. `TEST Anna`).
- **Arbetsfördelning:**
  - **ChatGPT:** Krav, texter, prioriteringar och granskning (via Issues / PR-kommentarer / `docs/`).
  - **Antigravity:** Utveckling, tekniska tester, dokumentation och Pull Requests.
  - **Jeanette (VD):** Beslut och godkännande innan publicering.

## Struktur
- `docs/` – Arbetsordrar, krav och integrationsguide för Ramona (`djuraccess.se`).
- `src/` – Källkod (sätts upp när första arbetsordern landat).
